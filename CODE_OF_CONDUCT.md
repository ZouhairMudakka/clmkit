# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. We want clmkit to be a welcoming, harassment-free space for everyone, whatever their
background or level of experience.

Report unacceptable behaviour privately to the maintainer through GitHub
(for example via [a private security advisory](https://github.com/ZouhairMudakka/clmkit/security/advisories/new)
if it needs confidentiality). All reports are reviewed and handled confidentially.
